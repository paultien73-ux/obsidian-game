

> **定位**：系列第三份文档，站在最高抽象层。技术版（《分层拆解沉淀》）给代码证据，玩法版（《玩法拆解沉淀》）给逐关档案；本文只回答两个问题——**把 18 关约 40 道谜题压到最简后，谜题一共有哪几类？它们靠什么模式组织起来？**
> 
> **方法**：对玩法版"逐关谜题档案"做二次抽象。把每道谜题拆成"藏（线索载体）× 变（脑力变换）× 输（答案物化）"三条轴，轴上取值的集合就是类型与模式。全文零代码符号，可直接当作解谜关卡的设计模式语言使用。

## 一、第一性结构：每道谜题都是一条"藏 → 变 → 输"流水线

```
线索载体（藏） ──→ 脑力变换（变） ──→ 答案物化（输）
信息藏在哪里      玩家脑子做什么     玩家手上做什么
```

任何一道谜题（不限于本作）都能拆成这三段：

| 段   | 要回答的问题        | 本作的取值集合                         |
| --- | ------------- | ------------------------------- |
| 藏   | 信息放在哪、怎么掩盖？   | 环境物件 / 文档纸条 / 图形画面 / 隐藏态（需显形）   |
| 变   | 对信息做什么才能得到答案？ | 读 / 查表 / 算 / 推 / 看 / 调知识 / 找    |
| 输   | 答案以什么形式交回游戏？  | 数字串 / 符号序列 / 开关位串 / 空间拖放 / 点击顺序 |

**洞察 1（类型由"变"决定）**：玩家给谜题归类的依据，既不是输入面板也不是线索载体，而是"我的脑子要干哪种活"。数字转盘只是皮肤——映射型、运算型、直读型谜题最终都落在数字转盘上，但它们是三种不同的谜题。

**洞察 2（三轴正交）**：藏、变、输互相独立、自由组合。同一个"变"（查表映射）可以藏在一面墙上、一张纸上、一张 X 光片里，也可以输进数字盘、颜色盘或开关排。**谜题库的规模 = 各轴取值的乘积，而不是各轴之和。**

## 二、谜题类型学：七种脑力变换

类型 = 玩家在"变"这一段做的脑力操作。全作约 40 道谜题归并为七型。

### T1 直读型（零变换）

- **定义**：线索明文给出答案，玩家只做格式转写。
- **实例**：纸条"箱子的密码是 427"（关 12）；时钟显示 12:55 → 1255（关 2）；油画"水的容量是 32 毫升和 18 毫升" → 3218（关 6）；紫光显字"暗门的密码是 5391"（关 9）。
- **存在意义**：教学与节奏调剂。每关至少留一道直读题建立信心；但全靠它就是填空不是解谜。
- **难度旋钮**：几乎没有——唯一的弱化手段是让载体难找（把纸条藏进油画背后）。

### T2 映射型（查表翻译）

- **定义**：线索给出一张"对照表"，玩家把一种符号翻译成另一种。
- **子模式**：表与查询对象分离（表在 A 处、要转的盘在 B 处——这是"双源合成"模式的种子）；映射方向可反考（给符号找数字 / 给数字找符号）。
- **实例**：猜拳胜者定数字 → 502（关 1）；箭头↔数字 `↑3↓2←8→5` → 3285（关 3）；颜色→双开关展开（关 7）；形状 ■●▲→5527（关 10）；鱼骨符号→井盖宫格 3674（关 17）；蜂巢编号顺序 13622（关 18）。
- **难度旋钮**：对照表的隐蔽度；映射链长度（一级 vs 两级，如"投影→图案→数字"）；符号与数字的语义距离（越不相干越难）。

### T3 运算型（数值加工）

- **定义**：线索给数字，玩家按规则算出答案。
- **三个子模式**（按规则来源递难）：
    1. **规则明示**：算式直接写出来——A+B+C=168（关 2）
    2. **规则样例**：给两条"错算式"让玩家归纳——32+44=26 → 加法结果减 50 → 4648（关 8）
    3. **常识规则**：不解释——生日+体重 → 8138（关 7）
- **实例**：求和 168（关 2）；变量代换 B-A、C-A、B+C → 4515（关 5）；百分比反推 27÷90%=30 → 3028（关 13）；倒序借位减法 52853（关 14）；时钟读数规则 140（关 18）。
- **难度旋钮**：运算步数（1 步 → 3 步）；规则是否显式；参与运算的数字是否需要跨线索收集。

### T4 逻辑型（约束推导）

- **定义**：线索给一组关系约束，玩家推导出唯一解。
- **实例**：五个不等式排出全序"红 > 黄 > 绿 > 蓝"（关 6）。全作仅此 1 处，但它是"推理感"最纯的类型——没有运算、没有查表，只有关系。
- **难度旋钮**：约束数与元素数的配比（约束恰好唯一确定 = 标准难度；留一条冗余约束可降难）。

### T5 视觉型（最大家族，13+ 处）

- **定义**：答案以图形属性存在，玩家"看出来"而不是"算出来"。
- **七种子变换**——这是本作最值得抄的细分库：

|子变换|玩法一句话|实例|
|---|---|---|
|过滤|忽略干扰维，只看目标特征|重影数字只读红色 → 8734（关 4）；字母海里找异类字母连成 635（关 17）|
|翻转|对称/负片/倒置后认读|亮灭互换（负片）→ 0357（关 18）；倒写符号调正 → 1459（关 14）；印章图案反序（关 13）|
|拼合|两份残片互补成完整信息|双纸条重叠，笔画互补拼出"六七三五"→ 6735（关 15）|
|旋转|旋转变形后认读|线路每次顺时针 45°，转完拼出 7429（关 18）|
|投影|三维↔二维换视角|砖块侧面投影对应图案（关 16）；折纸折痕展开显数 3642（关 16）|
|配对|图形轮廓两两对应|石堆红线轮廓配石碑图形 → 243（关 14）；电路板上排图案连下排芯片（关 1）|
|显形|隐藏层显现后才可读|条形码"写意地拼出"135921（关 9）；七段数码管按三原色拆出 423（关 13）；星空连线成数 937（关 4）|

- **难度旋钮**：干扰密度；变形幅度（小倒角 vs 整幅翻转）；是否需要道具才能看（放大镜/望远镜/光照——先用"藏"法降难，再谈"变"）。

### T6 知识型（本作点题特色，少而精）

- **定义**：变换规则来自玩家脑中的现实知识，游戏只给验证样例、不解释规则。本作专攻**汉字知识**。
- **实例**："四 = 5"因为"四"字 5 笔 → "六七五" = 424（关 10）；照书写笔顺描箭头认出 726（关 11）；石头剪刀布的文化常识（胜者定数）→ 502（关 1）。
- **为什么有效**：规则不用教，玩家自己"啊，原来如此"——aha 感全类型最强；且它把游戏标题"汉字的秘密"从题材变成了谜题机制本身。
- **可移植家族**：笔划数 / 笔顺 / 拼音首字母 / 偏旁部首数 / 成语缺字 / 天干地支序 / 生肖序。
- **难度旋钮**：知识的冷门程度（笔划是小学常识，天干地支是进阶）。

### T7 观察型（呼吸口）

- **定义**：无判定的"看"，答案由玩家自己记录。望远镜拖动星空，找到连线成数的星群 937（关 4）。
- **变体**：放大镜找隐藏物（关 9，带判定，归探索互动）。
- **存在意义**：全作唯一的零失败焦虑段，解谜节奏里的深呼吸。

### 类型分布统计

| 类型     | 约计  | 备注                          |
| ------ | --- | --------------------------- |
| T5 视觉型 | 13+ | 最大家族，插画的用武之地                |
| T3 运算型 | 7   | 第二                          |
| T2 映射型 | 6-7 | 与运算型并列第二梯队（关 1 猜拳题兼有 T6 成分） |
| T1 直读型 | 4   | 教学与调剂                       |
| 顺序操作   | 4   | 归入 §五 模式 7/8，不计入脑力类型        |
| T6 知识型 | 3   | 少而精，点题之笔                    |
| T7 观察型 | 1-2 | 节奏呼吸口                       |
| T4 逻辑型 | 1   | 点缀                          |

> **分布结论**："看"与"算"平分天下，"查表"紧随其后。玩家的主要脑力活动依次是**观察辨认 > 数值计算 > 符号翻译**；物理操作（转/拖/点序列）承担的是手感与时长，不是智力。

## 三、"藏"法：四类载体与显形时刻

### 3.1 线索载体的四类来源

|载体|说明|实例|
|---|---|---|
|环境即数据|场景物件本身就是数据源，谜题要求"读懂房间"|时钟 12:55（关 2）；X 光片上的身高体重（关 7）；油画里的毫升数（关 6）|
|文档纸条|最常用的规则/数据说明载体，每关 2-4 张"线索纸"|纸条、日记、病历、守墓人日志、工作证|
|图形画面|复杂规则画成图，一张图独立成义|笔顺箭头图（关 11）、折痕图（关 16）、蜂巢图（关 18）、三原色融合图（关 13）|
|隐藏态|信息在场但看不见，需显形（见 3.2）|白笔写的字、喷漆盖住的字、断电看不见的涂鸦|

### 3.2 显形时刻：信息揭示的唯一手法是"换图"

|叙事包装|物理手段|
|---|---|
|蜡烛照书 / 紫光照试卷 / 黄灯照 X 光 / 反光镜照书 / 火种点灯照隧道|光照|
|喷漆显墙字|化学|
|清水洗石头 / 抹布擦墙|物理|
|通电后墙上涂鸦显形|状态|

四种包装共用同一机制：**物品 A 解锁物品 B → B 换成"显形版"图片**。零新机制成本，一张新图 + 一句文案，换来全作最有记忆点的"发现瞬间"。

## 四、"输"法：皮肤层与类型解耦

### 4.1 两大皮肤家族

**A. 索引序列皮肤**——把答案表达为一串符号索引，本质都是"n 位、每位 k 选一"：

|皮肤|状态空间|什么时候用|
|---|---|---|
|数字转盘 / 键盘|0-9|默认皮肤，任何类型谜题的答案都能落进来|
|颜色盘|4-6 色|答案本身是颜色序列时（不等式排序、颜色映射）|
|图案盘|≤4 图案|答案是图形序列时（形状映射、投影配对）|
|方向盘|4/8 向|答案与方位相关（箭头映射）|
|开关排|0/1|二元答案（颜色→开关每位展开两位）|
|自定义符号盘 ■●▲|任意|主题化包装（汉字关的出口锁）|

**B. 空间/时间关系皮肤**——答案是空间位置或时间顺序，不是索引串：

|皮肤|玩法|实例|
|---|---|---|
|连线|上下排两两匹配|电路板连线（关 1）|
|拖放定位|物品拖到指定空间位，错位弹回|四符号拖四角（关 11）|
|顺序投放|同批物品按序放置，错序全弹回|三宝石蓝→红→黄（关 4）|
|点击序列|按规则依次点击|加减按钮序列（关 3）|
|拼图 / 滑块 / 旋转对位|块交换 / 推杆 / 转盘到位|点缀，各 1-2 处|

**洞察 3（皮肤不承载类型）**：皮肤只承载主题包装与操作手感。同一道映射型谜题——答案给数字就配数字盘，给颜色就配颜色盘，给图案就配图案盘。**选皮肤 = 问"答案的自然形态是什么"，而不是"我想要什么玩法"。**

## 五、玩法模式库：谜题如何嵌入关卡

类型回答"玩家想什么"，模式回答"谜题在关卡里怎么摆"。以下 8 个模式是本作真正的组织骨架。

### 模式 1 双源合成 ★ 全作第一模式

- **结构**：**规则与数据分放在两处**，玩家必须先各找到一半，拼出答案。
- **本作实例**：
    - 桌布写"实验结果 26/74/68"（数据）+ 显微镜显示"A+B+C"（规则）→ 168（关 2）
    - 符号刻字"A=3, B=7, C=8"（数据）+ 石板刻"B-A, C-A, B+C"（规则）→ 4515（关 5）
    - 病历写生日/体重（数据）+ 地板卡片"密码是生日+体重"（规则）→ 8138（关 7）
    - 铭牌写"32+44=26, 28+52=30"（规则样例）+ 工作证写"18+78、56+42"（题目数据）→ 4648（关 8）
    - 天花板数码管涂色（数据）+ 三原色融合图（规则）→ 423（关 13）
    - 岩石碎片图案（数据）+ 答案卡转向说明（规则）→ 13 连转（关 16）
    - 墙上涂鸦蜂巢图（数据）+ 提示图读序规则（规则）→ 13622（关 18）
- **为什么有效**：把一次解谜拆成两次探索，拉长流程；两半各自都看不懂，凑齐才"叮"——**合成感是解谜游戏最强的奖赏时刻**。
- **复用模板**：`<数据源：物件/纸条> + <规则源：另一物件> → <答案>`

### 模式 2 样例教学（从不写规则说明书）

- **结构**：游戏从不用文字陈述谜题规则，而是给 1-3 个已解的例子让玩家归纳，再给题目。
- **本作实例**：猜拳对照图 → 三道猜拳题（关 1）；"四 = 5"→"六七五 = ???"（关 10）；两条例子归纳"减 50"→ 4648（关 8）；时钟读数给三个完整例子 → 读目标钟面 140（关 18）。
- **变体·样例验证**：照片背面给 752，供玩家对照验证"圆=2、三角=7、方=5"的映射表（关 13）。
- **为什么有效**：归纳瞬间就是 aha 时刻；且规则不用写进 UI 文案，全部塞进插画。

### 模式 3 显形时刻

- **结构**：目标物在场上但呈隐藏态，找到"揭示道具"（光源/水/油漆/电源）后换图显形。显形本身即奖赏，显形之后往往接一道 T1 直读题（先给看，再谈想）。

### 模式 4 道具转化链

- **结构**：道具不直接开门，而是 A→B→C 多步变形，每步一次"换图"。
- **实例**：线+鱼钩→钓起石头（关 3）；晒干→点燃→火把→烧蛛网（关 5）；种子→花→果实→喂鸟（关 16）；磁铁吸出钳子→钳子剪铁丝网（关 17）；充电线→带电手电筒→照亮隧道（关 18）；剪刀→窗帘→抹布→擦墙显字（关 3）。
- **为什么有效**：收集感与合成感的复利；每一步的工程成本只是"换图 + 复用合成判定"。

### 模式 5 环境读数

- **结构**：场景物件本身就是数据源，谜题要求"读懂房间"。时钟 12:55（关 2）、油画毫升数（关 6）、病历（关 7）。
- **为什么有效**：让场景"活着"——房间不只是背景板，每个物件都可能藏数。

### 模式 6 阶段演进（场景状态机）

- **结构**：一个关键动作让整个场景换状态（换背景/换可达性），开启第二批谜题。
- **实例**：双沙漏开启 → 出现时空轮盘（关 15）；水闸把手 → 地下湖水位三次涨落、趁退潮通过（关 16）；电源总闸 → 全厂来电、停转风扇取齿轮（关 8）；通电 → 涂鸦显形（关 18）。
- **为什么有效**：一关多幕，体量翻倍而复用同一张地图；"变天"时刻是关卡记忆点。

### 模式 7 顺序敏感

- **结构**：材料与普通收集门相同，**投放顺序即答案**，放错全部弹回。三宝石蓝→红→黄（关 4）；四符号拖四角（关 11）。
- **为什么有效**：把"收集"升级为"解谜"，工程成本只是多一个顺序判定。

### 模式 8 超长序列分段验证

- **结构**：把长操作序列切段，每转对一段亮一颗收集灯，**错段不重来**。图腾 13 连转 `1×6 + 2×5 + 1×2`，分三段各配一盏灯（关 16）。
- **为什么有效**：分段验证把 13 次操作的挫败风险摊薄——**长操作不等于高难度，只等于高时长**，惩罚感由设计者精确控制。

## 六、统计规律与难度公式

### 6.1 组合公式

```
一道谜题 = 藏法(4) × 变换(7) × 皮肤(10)      —— 单题三维独立取值
一个关卡 = 门禁链骨架(4) × 模式 1-8 的编排
```

四种关卡骨架（线性主链 / 并行汇流 / 顺序敏感 / 多阶段）见玩法版 §7.1，此处不重复。

### 6.2 分布规律（90/10）

- **密码门 + 收集/工具门 + 线索纸**三类承担约 90% 谜题量；物理操作题型（拼图/滑块/旋转对位）只是点缀。
- 谜题机制是**常量**（十几个面板类复用全部 18 关），**变量全部在插画与线索内容**——开发成本大头是美术与文案，不是程序。
- 类型频次：视觉 > 运算 ≈ 映射 ≫ 直读/顺序 > 知识 > 逻辑/观察。
- 知识型只有 3 处，却是全作记忆点与标题来源——**点题类型要少而精**，一个游戏只需要一个"只属于它"的类型。

### 6.3 难度公式

```
难度 ≈ 变换深度 × 线索分散度 × 干扰量 − 显形辅助
```

|因子|取值示例|
|---|---|
|变换深度|直读 1 → 映射/单步运算 2 → 样例归纳/多步运算 3 → 两级映射、复合变形（投影+映射）4|
|线索分散度|单源明示 → 双源合成（模式 1）→ 三源跨场景（关 2：时钟+桌布+显微镜）|
|干扰量|重影数字的灰色干扰层、字母海的同类字母、双开关的默认态|
|显形辅助|光照/放大镜/望远镜先解决"看不清"，再考"想不出"——把读题成本与解题成本分离|

### 6.4 节奏配方（逐关档案归纳）

- **每关节奏**：探索拾取 → 1 个显形时刻 → 1-2 道主谜题（双源合成）→ 1 道直读喘息 → 出口。
- **教学关**（关 12）：全直读，3 步过关。
- **标准关**：双源合成 ×2 + 视觉型 ×1。
- **巨关**（关 14）：并行汇流 + 8 道门禁，收集线最长。
- **终章**（关 18）：谜题密度最高 + 一个阶段门收尾制造"变天"感。

## 七、照模式造一道新谜题（生成流程）

1. **先定答案**：挑一个 3-6 位、有"自然形态"的答案（数字串 / 颜色序 / 图案序 / 开关串 / 空间位置）。
2. **选变换类型**：从 T1-T7 挑一个，并配一个 §五 的嵌入模式（默认配双源合成）。
3. **写规则源与数据源**：规则走样例教学（给 2 个已解例子，不写说明书）；数据藏进载体（可选显形包装）。
4. **选皮肤**：答案的自然形态是什么盘，就用什么盘。
5. **自检**：
    - [ ]  规则可从场内归纳，不需要场外知识（T6 除外——T6 用的必须是大众常识）
    - [ ]  规则源与数据源分开摆放，两条路径各有一次探索
    - [ ]  答案在场内可验证（留一个可对照的样例）
    - [ ]  至少一次"叮"：显形 / 合成 / 归纳三选一
    - [ ]  按难度公式给四个因子打分，落在该关曲线位上

## 附录：一页速查

**七型**：读（直读）· 查（映射）· 算（运算）· 推（逻辑）· 看（视觉七变形：过滤/翻转/拼合/旋转/投影/配对/显形）· 知（知识）· 找（观察）

**八模式**：双源合成 ★ · 样例教学 · 显形时刻 · 转化链 · 环境读数 · 阶段演进 · 顺序敏感 · 分段验证

**一个公式**：谜题 = 藏(4) × 变(7) × 输(10)；难度 ≈ 变换深度 × 分散度 × 干扰量 − 显形辅助

**三条洞察**：类型由"变"决定，皮肤只是包装；三轴正交，谜题库 = 乘积不是求和；点题类型少而精。
